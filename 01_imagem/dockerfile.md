# 🐋 Criando um dockerfile do zero

O dockerfile é o arquivo de instruções criação de imagem (Sistema Operacional, Pacotes, cópia de arquivos e até mesmo estabelecer ponto de montagem de volumes).

1. Crie um arquivo texto, neste arquivo será informado a configuração do que é esperado no container que irá utilizar essa imagem. No exemplo abaixo será criada uma imagem com base Ubuntu + Ferramenta Terraform + Instalação do AWS CLI
